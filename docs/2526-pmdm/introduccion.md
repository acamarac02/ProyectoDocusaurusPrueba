# Programación de Multimedia y Dispositivos Móviles (PMDM)

![Android Development Banner](/img/android-banner.png)

¡Bienvenido al módulo de **Programación de Multimedia y Dispositivos Móviles**! En este curso exploraremos el apasionante mundo del desarrollo de aplicaciones para el ecosistema Android, centrándonos en las mejores prácticas actuales de la industria.

## 📱 ¿Qué es PMDM?

Este módulo está diseñado para proporcionar las habilidades necesarias para desarrollar aplicaciones móviles nativas y multiplataforma, integrando elementos multimedia y aprovechando las capacidades de hardware de los dispositivos modernos.

## 🎯 Objetivos del Curso

Durante este año escolar, nos enfocaremos en:

- **Dominar Kotlin**: El lenguaje de programación preferido por Google para el desarrollo en Android.
- **Arquitectura de Software**: Implementar patrones como MVVM (Model-View-ViewModel) para crear apps escalables.
- **Jetpack Compose**: Construir interfaces de usuario modernas y declarativas.
- **Integración de Servicios**: Aprender a consumir APIs REST y trabajar con persistencia de datos (Room, Firebase).
- **Multimedia**: Gestión de audio, vídeo y gráficos en aplicaciones móviles.

## 🛠️ Stack Tecnológico

Utilizaremos herramientas de vanguardia para asegurar un aprendizaje alineado con el mercado laboral:

| Herramienta | Uso |
| :--- | :--- |
| **Android Studio** | El IDE oficial de desarrollo. |
| **Kotlin** | Lenguaje principal de programación. |
| **Jetpack Compose** | Framework moderno para UI. |
| **Firebase** | Backend as a Service (Auth, Firestore, Cloud Messaging). |
| **Git / GitHub** | Control de versiones y colaboración. |

---

> [!TIP]
> Asegúrate de tener instalada la última versión de **Android Studio (Ladybug o superior)** para seguir las prácticas del curso sin problemas de compatibilidad.
